## Problem Title
SIH 26033: Multiple intermediaries reduce farmers earnings and increase consumer prices.

## Problem Creater's Organization
Ministry of Consumer Affairs, Food & Public Distribution

## Theme
Agriculture, FoodTech & Rural Development

## Problem Description
Expected Solution: Create a digital marketplace that:

• Connects farmers/FPOs directly with consumers and bulk buyers.
• Provides logistics support.
• Uses AI for demand forecasting and route optimization.

Benefits:

• Better prices for farmers.
• Lower prices for consumers.
• Reduced supply chain inefficiencies.

## Proposed Solution

To increase farmers' earnings and benefit consumers, intermediaries should be removed from the farm-to-consumer supply chain.
 First, a web page should be created for farmers to list the prices, quality, and cultivation locations of their vegetables and fruits. 
 When a bulk buyer places an order for produce, the web page will calculate the shortest route to the nearest warehouse storing those items.
  This shortest distance will then be displayed on the website for the bulk buyer, and delivery will be free for the bulk byer for the particular distance .
   Once the bulk buyer places an order and the farmer agrees to the offered price, the farmer will accept the deal and deliver the fruits and vegetables directly to the bulk buyer. 
   So if we use this process the farmer will earn some more money and if will be profit to the consumer.

## Feasibility and Viability

Feasibility: This project is possible to build. The website can be easily made using Python, Django, HTML, CSS, and MongoDB. Using a phones GPS is simpler and cheaper than buying separate GPS devices.
Viability: This idea will work well in real life. Removing intermediate helps farmers earn more money, and shorter delivery routes save fuel. However, you must manage storage well so vegetables do not spoil before they are sold.



## Impact and Benefits
Eliminating intermediate will improve the profit of the farmer .
If we wait for the order for bulk byer for weeks the vegetables will be spoiled.
If we calculate the shortest distance the fuel will be saved emission of carbon will reduce.

## Research and References
Research and References:

Studies on farming show that removing middlemen helps farmers earn more money and lowers prices for buyers. Research on online farm markets and GPS tracking proves that using websites and shortest-route maps saves fuel, reduces pollution, and keeps vegetables fresh before they spoil.
